# ASM To Machinecode Py

Part of [`Systems_Programming`](https://github.com/CoderFatherBB/Systems_Programming) at `ASM_to_MachineCode_Py`.

## About

`ASM To Machinecode Py` contains notebook-based experiments and supporting files for this part of `Systems_Programming`.

## Contents

- `asm_code.txt`: data or support artifact.
- `ASM_to_Variant1.ipynb`: Jupyter notebook.
- `intermediate_code.txt`: data or support artifact.
- `literal_table.txt`: data or support artifact.
- `machine_code.txt`: data or support artifact.
- `mot_table.txt`: data or support artifact.
- `output.txt`: data or support artifact.
- `output_tables.txt`: data or support artifact.
- `register_table.txt`: data or support artifact.
- `symbol_table.txt`: data or support artifact.
- `Variant1_to_MachineCode.ipynb`: Jupyter notebook.

## Use

Open the notebooks in Jupyter, VS Code, or Google Colab and run the cells in order after installing the required Python packages.
